# 326FinalProject
Repository for the INST326 Final Group Project

This program is a contact manager application that helps people organize their 
contacts. There is a Phonebook class and a Contact class. The Contact class 
represents one contact object which can include the person's name, address, 
phone number, and email. The Phonebook class contains a dictionary where contact 
objects are stored and methods that enable the user to add, edit, or remove a 
contact, get the total number of contacts in their Phonebook, and clear all 
their contacts or export them to a csv file.

To run the program from the command line, download the file and ensure that your
terminal is in the same directory as the file. Afterward, run 
'python3 INST326_FP.py'. The application will then begin to prompt the user with
input instructions. Follow the instructions to use the program.

The main function will provide the user with a menu list of actions that the
application can do. Input the menu number of the action to choose it.
Afterwards, follow the other input prompts of the application. To quit the 
program, input 'n' when prompted with 'Run again? y/n:'.
